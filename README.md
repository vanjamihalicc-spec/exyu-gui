# EX-YU kalendar

Moderno grafičko sučelje (GUI) napisano u Pythonu i GTK 3 biblioteci za prikaz povijesnih, kulturnih i znanstvenih događaja iz bivše države.

## Funkcionalnosti
- **Vizualni pregled:** Jednostavan prikaz kalendarskih dana kroz GTK sučelje.
- **Dodavanje podsjetnika:** Ugrađen sustav za trajno zapisivanje vlastitih podsjetnika izravno kroz aplikaciju u bazu `~/.calendar/calendar`.
- **Brisanje zapisa:** Integrirana ikona koša za smeće za brzo uklanjanje dodanih podsjetnika.
- **Desktop integracija:** Prilagođeni pokretač s natpisom EX-YU za izbornik aplikacija.

## Pokretanje aplikacije
Za pokretanje aplikacije iz terminala osigurajte da imate instalirane GTK 3 ovisnosti i pokrenite:
```bash
python3 exyu_calendar.py
```
